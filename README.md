# Mohammed Jamai — Portfolio

A responsive engineering portfolio for Mohammed Jamai.

## Navigation flow

- Logo → Landing Page
- Landing Page → Discover Profile → Profile
- Profile contains the compact four-area capability summary, education, certifications and languages.
- Experiences contains professional and project-related experience plus resume downloads.
- Projects contains the six featured projects and the complete technical skills stack.
- Resources contains three content types: Articles & Notes, Documents & Tools, and Recommendations.
- Contact contains professional contact details and resume links.
- Terms of Use is available from the sidebar on every page.

## Visual identity

The site uses the approved MJ monogram supplied for the portfolio, with a restrained engineering/editorial visual system and green as the primary interaction accent.
